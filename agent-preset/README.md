# 自定义 Agent 预设：严格交付模式（中文）

基于对本机 194 个会话 / 1369 条真实发言 + 31 条事故案例的复盘提炼，把反复出现的返工点固化成 Agent 的行为纪律。

## 这个预设解决什么

复盘里最高频的五类摩擦，正好对应下面 11 条纪律：

| 摩擦（来自复盘） | 对应纪律 |
| --- | --- |
| 服务中断 / 反复启动 73 条、改了没生效 24 条 | ⑤ 生效证据（重启 + 日志时间戳 + 版本号） |
| 同类问题要全量扫 47 条 | ④ 交付附验收清单、逐条核销 |
| 口径 / 规则不一致 13 条（卡片 15 vs 列表 173） | ⑥ 一个概念一处定义 + 互斥断言 |
| 静默失败（698 轮、41 条/轮） | ⑦ 禁止空 catch，兜底只兜预期错误 |
| 你在当验收器（12% 纯确认 + 13% 验证追问） | ② 先给方案、④ 验收清单、⑩ 一次只问一个问题 |

## 安装

```bash
# 1) 安装预设
cp -r agent-preset/verified-zh ~/.dsh/.agent-presets/

# 2) 一并安装技能（预设会用到的 4 个技能）
cp -r ../skills/* ~/.dsh/skills/

# 3) 重启 DSH 或重新打开「设置 → Agent 预设」，即可看到「严格交付模式（中文）」
```

安装后在新建会话时选择该预设即可；也可设为新任务默认。

## 与「标准模式（中文）」的差别

- **工具集完全一致**（bash / 文件 / 技能 / 子代理 / 工作流 / 目标 / 待办 / 提问 / 联网 / 交付物），
  不削减能力，只约束行为——避免"为了纪律牺牲手段"。
- **persona 里注入 11 条交付纪律**，并在冲突时声明"以纪律为准"。

## 自定义

- 改行为：编辑 `agent.cordis.yml` 里 `persona.suffix` 的那段纪律文本。
- 改工具：`disabled: true` 可关掉某个工具行（例如不想让 Agent 联网就关 `tool-web`）。
- 想更严格：把 `plan-mode` 的 section 保留，并在纪律里加"方案未确认前禁止任何写操作"。
